# Zombie Cats

## About Me
An arcade zombie shooter with cats using SDL3 and SDL3Image! Styled around Plants vs Zombies and Ghost and Goblins

## How do I play this?
[Download from GitHub Releases](https://github.com/NotTacos2/zombiecats/releases/tag/v1)

## Controls
- A or D, Left arrow or Right arrow to move, space bar to shoot.

## Features:
- 2D Arcade zombie shooter with cats
- 3 Types of zombies, regular, cone, and bucket.
- Health system
- Score system
